# Bundled fonts

The interface fonts, the same on every desktop. Stored gzip-compressed,
otherwise unmodified. Static weights only: GPUI draws a variable font at its
regular weight.

| Files | Source | Licence |
|---|---|---|
| `NunitoSans-*.ttf.gz` | Nunito Sans, from [googlefonts/NunitoSans](https://github.com/googlefonts/NunitoSans/tree/main/fonts/ttf) | SIL Open Font License 1.1, see `OFL-NunitoSans.txt` |
| `BricolageGrotesque-*.ttf.gz` | Bricolage Grotesque, from [ateliertriay/bricolage](https://github.com/ateliertriay/bricolage/tree/main/fonts/ttf) | SIL Open Font License 1.1, see `OFL-BricolageGrotesque.txt` |

The source form of these files is the files themselves (decompress with
`gunzip`), or the upstream repository linked above.
