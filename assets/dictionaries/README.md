# Bundled spelling dictionaries

Used for spell checking outside Windows when the system has no Hunspell
dictionary for the language. Stored gzip-compressed, otherwise unmodified.

| Files | Source | Licence |
|---|---|---|
| `fr.aff.gz`, `fr.dic.gz` | Grammalecte French dictionary 7.7 ("classique"), from [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries/tree/master/fr_FR) | MPL 2.0, see `README_fr.txt` |
| `en_US.aff.gz`, `en_US.dic.gz` | SCOWL-based en_US dictionary, from [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries/tree/master/en) | SCOWL / BSD-style, see `README_en_US.txt` |

The source form of these files is the files themselves (decompress with
`gunzip`), or the upstream repository linked above.
